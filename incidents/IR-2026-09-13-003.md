\## Key Note

Initial simulation failed — schtasks requires SYSTEM/Admin privileges.

Fix: Run from Administrator PowerShell.

Also required enabling audit policy for Other Object Access Events.



\## Lessons Learned

\- Scheduled task creation requires Admin context to generate EventID 4698

\- Default audit policy does not log task creation

\- Fix: auditpol /set /subcategory:"Other Object Access Events" /success:enable

\- Wazuh Rule 60228 fires on EventID 4698 automatically once audit is enabled

\- Task name disguised as WindowsUpdateHelper — common real-world tactic
