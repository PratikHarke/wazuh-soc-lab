## Root Cause
Simulated credential brute force using Hydra v9.6 with rockyou.txt wordlist against the SSH daemon on localhost. SSH root login was permitted with password authentication enabled — a misconfiguration that allowed the attack surface.

## Containment
Attack was simulated in an isolated lab environment (VirtualBox bridged adapter). The SSH daemon triggered `srclimit_penalise` with a 20-second IPv4 penalty after repeated failures, partially rate-limiting the attack.

## Remediation
| Action | Priority |
|---|---|
| Disable SSH password authentication (use key-based auth only) | P1 |
| Set PermitRootLogin no in /etc/ssh/sshd_config | P1 |
| Implement Wazuh active response to auto-block after N failures | P2 |
| Restrict SSH access to management IPs via firewall rules | P2 |
| Enable fail2ban as additional defense layer | P3 |

## Severity
**P2 — High** (Credential access technique on active Linux endpoint)
