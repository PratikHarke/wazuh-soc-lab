# IR-2026-09-25-006 — Automated Active Response: IP Block via firewall-drop

## Summary
Following SSH brute force detection on the Kali Linux endpoint (agent ID 004), Wazuh's Active Response module automatically executed the `firewall-drop` script, inserting an iptables DROP rule for the attacking IP. This confirms full automated detection-to-containment capability with zero manual intervention.

## Lessons Learned
- Full detection-to-containment pipeline operational on Linux endpoint
- Active Response executes locally on the agent (not on the manager)
- 300s timeout appropriate for lab; production would use longer or permanent block
- Loopback (127.0.0.1) cannot be the attack source for firewall-drop to work — requires real source IP
- Wazuh server runs Amazon Linux 2023 in FIPS mode — external SSH tools cannot negotiate with Kali's modern OpenSSH
