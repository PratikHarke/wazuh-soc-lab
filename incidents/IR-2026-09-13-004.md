\## Attack Description

Adversary dropped a batch file named TestHelper.bat into the

user startup folder to achieve persistence on logon. File was

detected immediately by Wazuh FIM realtime monitoring.

\## MITRE Mapping

Tactic: Persistence

Technique: Boot or Logon Autostart Execution — Startup Folder

ID: T1547.001

Evidence: FIM realtime Rule 550 fired on Startup folder write



\## Detection

Rule ID: 550

Rule Level: 7

Description: Integrity checksum changed

Log Source: Wazuh FIM realtime module

Monitored path: %APPDATA%\\...\\Startup (configured in ossec.conf)



\## Why This Matters

Startup folder is a classic persistence mechanism.

Wazuh detected the file within seconds due to realtime=yes config.

Without FIM realtime, detection would only occur at next scan (5 min delay).



\## Lessons Learned

\- FIM realtime=yes is essential for immediate persistence detection

\- alert\_new\_files=yes generates alerts for newly dropped files

\- Rule 550 fires on any file change in monitored paths

\- Both file creation AND deletion generate separate FIM events
